Quick Look for FITS · macOS

See inside FITS files with one key.

Select a .fits file in Finder and press . uFits shows the image, the spectrum or light curve, the catalog, the table or the header at once, even when the file holds gigabytes.

Install: paste this in Terminal
$ curl -fsSL https://github.com/lmytime/uFits/releases/latest/download/install.sh | sh

macOS 11 or later Apple silicon and Intel 1 MB Download the disk image

What it reads

Images, cubes, tables and every header, from the files you already have. Written here the way a FITS header is: keyword, value, comment.

SIMPLE=TStandard FITS, from any telescope or pipeline
IMAGES='every BITPIX'BSCALE and BZERO applied, blank pixels transparent, an automatic stretch
CUBES='a plane slider'RGB cubes and Bayer camera frames in colour
FPACK='RICE_1 GZIP_1 GZIP_2'and PLIO_1: only the tiles on show are decompressed
PLOTS='spectra, light curves'TESS, Kepler, SDSS, HST and JWST x1d, X-ray
SKYMAP='RA, Dec'catalogs as a map of the sky, RA growing to the left, crowded fields shaded
TABLES=1000000rows scroll smoothly; ⌘C copies the ones you select
HEADER='in columns'CONTINUE strings joined, HIERARCH keywords in full; ⌘F finds
HDUS='all of them'a menu switches between SCI, ERR, DQ, tables and the rest
THUMBTIM=0.02[s] for a Finder thumbnail: it reads only the pixels it shows
APPSIZE='1 MB'a native, universal app with no dependencies
END
